# Трекер проекта

Порядок работы над сайтом. **Одна строка = одна сессия.** Взял первую незакрытую
задачу → сделал → билд зелёный → проверил в браузере → коммит → отметил здесь →
переписал `.claude/HANDOFF.md` → стоп.

Метод целиком — `docs/redesign-playbook.md` (читается по разделам, не целиком).

Статусы: `☐` не начата · `⏳` в работе · `✅` готово · `⏸` ждёт ответа заказчика
