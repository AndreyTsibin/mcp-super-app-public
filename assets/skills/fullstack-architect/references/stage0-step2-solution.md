### 2. Назови 3-5 главных функций для MVP

**Что такое MVP:** Минимальная версия продукта с самыми важными функциями. Без которых продукт не имеет смысла.

**Примеры:**

✅ **Приложение для записи к парикмахерам:**
1. Просмотр свободного времени у мастеров
2. Бронирование времени онлайн
3. Уведомления (SMS/email) за день до записи
4. Оплата онлайн
5. Отмена записи (не позднее чем за 24 часа)

✅ **SaaS для ресторанов:**
1. Приём заказов на планшете официанта
2. Отправка заказа на кухню автоматически
3. Отслеживание статуса заказа (готовится/готов)
4. Расчёт счёта
5. Простая аналитика (сколько заказов за день)
