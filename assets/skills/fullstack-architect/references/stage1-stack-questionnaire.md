# Этап 2: Выбор технологического стека

Отлично! PRD готов. Теперь подберём технологии под твой проект.

## Что такое "стек"?

**Простыми словами:** Набор инструментов для разработки. Как у мастера — молоток, пила, дрель. У разработчиков — языки программирования, фреймворки, базы данных.

**Почему это важно:** Правильный стек = быстрая разработка + низкая стоимость + лёгкое масштабирование.

## Вопросы для выбора стека

### 1. Какой опыт у команды?

**Выбери вариант:**

🟢 **Есть опыт с конкретными технологиями**
→ Скажи, какими (например: "React", "Python Django", "Node.js")
→ Я подберу стек на основе того, что знаете

🟡 **Есть общий опыт программирования, но не с конкретным стеком**
→ Я предложу самые популярные и простые в изучении технологии

🔴 **Опыта нет, планируем использовать no-code или нанять разработчиков**
→ Я подберу либо no-code решение, либо стек, который легко найти на рынке

---

### 2. Какая ожидаемая нагрузка?

**Сколько пользователей будет работать одновременно?**

⚡ **До 1,000 пользователей в день** (~50 одновременных)
- Подойдёт: Простой стек (даже shared hosting за \$5/мес)
- Пример: Локальный бизнес, нишевый SaaS

⚡ **1,000 - 10,000 пользователей в день** (~500 одновременных)
- Подойдёт: VPS (\$20-50/мес) или Serverless
- Пример: Региональный сервис, B2B SaaS

⚡ **10,000+ пользователей в день** (~1,000+ одновременных)
- Подойдёт: Cloud infrastructure с автомасштабированием
- Пример: Популярное приложение, маркетплейс

⚡ **Высоконагруженная система (100,000+ одновременных)**
- Подойдёт: Микросервисы, Kubernetes, CDN
- Пример: Социальная сеть, финтех

**Подсказка:** Для MVP почти всегда достаточно первого или второго варианта.

---

### 3. Тип проекта?

**Выбери наиболее подходящий:**

📱 **SaaS приложение** (подписка, личный кабинет)
- Пример: CRM, таск-менеджер, аналитика
- Стек: Обычно веб-приложение с авторизацией и базой данных

🛒 **E-commerce / Маркетплейс** (каталог, корзина, оплата)
- Пример: Интернет-магазин, маркетплейс фрилансеров
- Стек: Веб-приложение + платёжная система (Stripe/PayPal)

🎛️ **Admin Dashboard / Внутренний инструмент**
- Пример: Панель управления для сотрудников, CMS
- Стек: Можно проще, т.к. мало пользователей

🔌 **REST/GraphQL API** (без UI, только backend)
- Пример: API для мобильного приложения, интеграция с другими сервисами
- Стек: Backend-only (Node.js, Python, Go)

🌐 **Landing Page + CMS** (сайт-визитка + блог)
- Пример: Корпоративный сайт с новостями
- Стек: Next.js + Headless CMS (Strapi, Sanity)

📲 **Mobile App** (iOS/Android приложение)
- Пример: Приложение для доставки, социальная сеть
- Стек: React Native / Flutter + Backend API

---

### 4. Специальные требования?

**Есть ли что-то особенное?**

🔐 **Высокие требования к безопасности**
- Пример: Финтех, медицина, персональные данные
- Влияние: Потребуется шифрование, аудит безопасности, compliance

💳 **Нужна интеграция с платёжными системами**
- Пример: Stripe, PayPal, Robokassa
- Влияние: Добавим библиотеки для платежей

📧 **Нужна email рассылка**
- Пример: Уведомления, newsletters
- Влияние: Интегрируем SendGrid или AWS SES

📊 **Нужна аналитика и отчёты**
- Пример: Дашборды, графики, экспорт в Excel
- Влияние: Добавим библиотеки для визуализации (Chart.js, D3.js)

🌍 **Мультиязычность**
- Пример: Сайт на русском и английском
- Влияние: i18n библиотеки

🔔 **Real-time уведомления**
- Пример: Чат, уведомления о новых заказах
- Влияние: WebSockets или Server-Sent Events

## Популярные стеки (референс)

**Не обязательно читать — просто для понимания:**

### Стек #1: Next.js Full-Stack (дефолт 2026, самый быстрый для MVP)
```
Frontend: Next.js 16 (React 19, App Router + RSC) + TypeScript
Styling: Tailwind CSS 4 + shadcn/ui
Backend: Server Actions + Route Handlers (встроенные)
Database: PostgreSQL (Supabase с RLS, или Neon)
ORM: Drizzle (лёгкий, type-safe) или Prisma
Auth: Better Auth (или NextAuth/Auth.js)
Payments: Stripe   Email: Resend
Hosting: Vercel (бесплатно для MVP)
```
**Плюсы:** Всё в одном, фронт+бэк в одной кодовой базе, бесплатный старт, \$0/мес на MVP
**Минусы:** Всё на JavaScript/TS (если команда на Python — см. Стек #3)
**Стоимость:** \$0/мес на старте, <\$200/мес на ~\$1K MRR

### Стек #2: React (Vite) + Node API (классика, гибкая)
```
Frontend: React 19 + TypeScript + Vite, Tailwind + shadcn/ui
Backend: Node.js + Hono/Fastify (или Express)
Database: PostgreSQL + Drizzle
Hosting: Frontend на Vercel/Cloudflare, Backend на Railway/Fly.io
```
**Плюсы:** Чёткое разделение фронт/бэк, гибкость, отдельный масштабируемый API
**Минусы:** Две части настраиваются и деплоятся раздельно

### Стек #3: Python Full-Stack (если команда на Python)
```
Frontend: React 19 + TypeScript + Vite, Tailwind + shadcn/ui
Backend: Python 3.12+ + FastAPI
Database: PostgreSQL + SQLAlchemy 2.0
Hosting: Frontend на Vercel, Backend на Railway/Fly.io
```
**Плюсы:** Родной для Python-команд, силён для ML/data-фич
**Минусы:** Фронт и бэк раздельно; меньше «всё-в-одном» решений, чем у Next.js
