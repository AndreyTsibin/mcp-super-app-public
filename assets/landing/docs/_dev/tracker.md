# Трекер сайта

Порядок сборки. **Одна строка = одна сессия.** Взял первую незакрытую задачу →
сделал → `npm run build` зелёный → проверил в превью → коммит → отметил здесь →
переписал `.claude/HANDOFF.md` → стоп.

Флоу целиком — `docs/landing-flow.md`. Стандарты читаются по одному, в той
задаче, где нужны: не грузи их все заранее.

Статусы: `☐` не начата · `⏳` в работе · `✅` готово · `⏸` ждёт ответа пользователя
