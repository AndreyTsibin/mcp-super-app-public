# Установка mcp-super-app

Эта инструкция написана для **Claude Code** — агент читает её и выполняет шаги сам.
Человеку ничего настраивать вручную не нужно.

---

## Инструкция для агента

Ты устанавливаешь локальный MCP-сервер `mcp-super-app` на машину пользователя.
Пользователь скорее всего **не разработчик** — не задавай ему технических вопросов,
не проси лезть в конфиги. Объясняй простыми словами, что происходит, и делай сам.

Выполни шаги строго по порядку. Если шаг падает — остановись, объясни причину
человеческим языком и предложи, что делать.

### Шаг 1 — проверь окружение

```bash
node -v
git --version
```

Нужен **Node.js 20 или новее**. Если Node нет или он старее 20 — скажи об этом
пользователю и предложи поставить: `brew install node` (macOS) или скачать
с <https://nodejs.org> (Windows и всё остальное). Git — с <https://git-scm.com>.
Дальше не иди, пока Node не встанет.

### Шаг 2 — склонируй репозиторий

Ставь в домашнюю папку пользователя, если он не сказал иначе:

```bash
git clone https://github.com/AndreyTsibin/mcp-super-app-public.git ~/mcp-super-app
```

Если папка `~/mcp-super-app` уже существует — не перезаписывай. Зайди в неё
и сделай `git pull` вместо клонирования.

### Шаг 3 — установи зависимости и собери

```bash
cd ~/mcp-super-app && npm install && npm run build
```

Должна появиться папка `dist/` с файлом `index.js`. Проверь:

```bash
ls ~/mcp-super-app/dist/index.js
```

### Шаг 4 — подключи сервер к Claude Code

```bash
claude mcp add mcp-super-app -s user -- node <АБСОЛЮТНЫЙ_ПУТЬ>/dist/index.js
```

Флаг `-s user` = сервер доступен во всех проектах, а не только в текущем.

**Подставь настоящий абсолютный путь**, не `~` и не относительный: конфиг хранится
глобально и разворачивается не из той папки, где ты сейчас стоишь. Узнай путь
заранее (`pwd` в папке репозитория) и подставь целиком — например
`/Users/имя/mcp-super-app/dist/index.js` на macOS или
`C:\Users\Имя\mcp-super-app\dist\index.js` на Windows.

Обновляется сервер вручную (см. раздел «Обновление» в конце файла) — автообновления
нет намеренно.

Если команда ругается, что сервер с таким именем уже есть — сначала
`claude mcp remove mcp-super-app -s user`, потом повтори.

### Шаг 5 — ключ OpenRouter (только если нужна генерация картинок)

Инструмент `create_image` требует свой ключ OpenRouter. Все остальные
инструменты работают без каких-либо ключей.

Спроси пользователя, нужна ли ему генерация картинок.

- **Не нужна** → пропусти шаг, всё уже готово.
- **Нужна** → объясни, что нужно:
  1. Завести аккаунт на <https://openrouter.ai>, пополнить баланс (генерация
     платная, порядка \$0.04 за картинку) и создать ключ на
     <https://openrouter.ai/keys>.
  2. Создать файл `~/mcp-super-app/.env` и вписать в него одну строку:

     ```
     OPENROUTER_API_KEY=свой-ключ-сюда
     ```

  **Ключ пользователь вписывает сам** — не проси его диктовать ключ тебе в чат.
  Можешь создать пустой `.env` из шаблона (`cp .env.example .env`) и сказать,
  какую строку в нём заменить.

`.env` лежит в `.gitignore` — в репозиторий он не утечёт.

### Шаг 6 — проверь, что всё работает

Скажи пользователю: **перезапустить Claude Code** (закрыть и открыть заново) —
без этого новый сервер не подхватится.

После перезапуска инструменты `bootstrap_project`, `install_skill`,
`create_website`, `install_guard`, `create_image`, `optimize_images`,
`search_icons`, `get_icon` должны быть доступны в любом чате.

Проверить список подключённых серверов:

```bash
claude mcp list
```

## Что делать, если не заработало

| Симптом | Причина и что делать |
|---|---|
| Инструментов нет в чате | Claude Code не перезапущен. Закрой и открой заново. |
| `Cannot find module .../dist/index.js` | Не прошёл `npm run build`. Повтори шаг 3. |
| `command not found: claude` | Claude Code стоит не как CLI. Подключи сервер вручную — см. раздел «Подключение к Claude Code» в [README.md](README.md). |
| `create_image` ругается на ключ | Нет `.env` или в нём неверный ключ. См. шаг 5. |
| `install_guard` работает, но ничего не блокирует | Не установлен `jq`. macOS: `brew install jq`. Windows: `winget install jqlang.jq`. |

## Обновление до свежей версии

Обновление ручное. Автообновления у сервера нет намеренно: скрипт-обёртка, которая
этим занималась, была bash-овой и на Windows не запускалась, а держать разное
поведение на разных ОС ради неё не стоит.

Скажи Claude Code «обнови mcp-super-app» — он выполнит:

```bash
cd ~/mcp-super-app && git pull && npm install && npm run build
```

После этого **перезапусти Claude Code** — сервер подхватится обновлённым.

Если `git pull` ругается, что перемотка невозможна (`not possible to fast-forward`),
значит история репозитория переписана. Тогда пусть агент синхронизирует ветку
с `origin/main` жёстко и пересоберёт. `.env` с ключом при этом не пострадает —
он не в git, и папку удалять не нужно.
